

🚀 VPN Panel — Установщик (Мастер + Ноды)

Установка VPN Panel + Telegram-ботов на чистый Ubuntu-сервер (VPS) и подключение дополнительных нод.

## 📋 Требования
- Ubuntu 22.04 / 24.04 (чистый сервер)
- Root-доступ по SSH
- **Токен доступа** (личный токен GitHub с правами `repo`, выдается автором проекта)

---

## 🖥️ ЧАСТЬ 1: Установка Мастера (Главный сервер)

1. Зайди на сервер по SSH (root).
2. Выполни команду:
```bash
bash <(curl -Ls https://raw.githubusercontent.com/zotac85/vpn-install_1.0/main/install.sh)
```

3. Скрипт запросит Токен доступа. Вставь свой токен (он сохранится в /root/.vpn-panel.token).
4. Дождись завершения. После установки запусти панель командой vpn.
5. В панели настрой Telegram-ботов (пункт 7).

---

🌍 ЧАСТЬ 2: Установка Ноды (Дополнительный сервер)

⚠️ Важно: Нода настраивается ДО добавления её в панель Мастера!

1. Зайди на чистый сервер ноды по SSH.
2. Создай файл с токеном (используй тот же токен, что и на Мастере):

```bash
echo "ТВОЙ_ТОКЕН_СЮДА" > /root/.vpn-panel.token
chmod 600 /root/.vpn-panel.token
```

3. Запусти установку ноды:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/zotac85/vpn-panel/main/install-node.sh)
```

4. Скрипт спросит порты. (По умолчанию WS: 2052, SSH: 22. Можешь изменить WS на 80, если нужно).

---

🔗 ЧАСТЬ 3: Подключение Ноды к Мастеру

Вернись на Мастер (Германия), запусти панель vpn и зайди в 9) Управление нодами:

1. 1) Добавить ноду — введи IP ноды и порты (те, что указывал при установке).
2. 4) Закинуть SSH-ключ на ноду — выбери ID новой ноды, чтобы Мастер скопировал свои ключи.
3. 2) Проверить все ноды (SSH) — статус должен стать online.
4. 7) Синхронизировать всех юзеров на ноды — создаст всех текущих клиентов на новой ноде.

Готово! Клиенты получат .dark файлы от новой локации.
