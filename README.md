# 🚀 VPN Panel — Установщик

Установка VPN Panel + Telegram-ботов на чистый Ubuntu-сервер (VPS).

## 📋 Требования

- **Ubuntu 22.04 / 24.04 / 26.04** (чистый сервер)
- **Root-доступ** по SSH
- **Токен доступа** (выдаёт @ArsenGuro лично)

## ⚡ Установка одной командой

Зайди на сервер по SSH (**root**) и выполни:


bash
bash <(curl -Ls https://raw.githubusercontent.com/zotac85/vpn-install_1.0/main/install.sh)


Скрипт:

1. Спросит токен доступа (выдаётся лично)
2. Загрузит VPN Panel
3. Запустит установщик
4. Создаст меню для настройки

🔑 После установки

· Запусти панель: vpn
· Создай 2 бота у @BotFather:
  · Основной бот (для выдачи ключей)
  · Бот поддержки
· Введи токены ботов через панель (пункт 7) 💎 Telegram-бот)
· Настрой остальное через панель

📖 Подробная инструкция

Полная инструкция со всеми шагами — в отдельном документе (прилагается вместе с токеном).
